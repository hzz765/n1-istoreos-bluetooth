Scope
Read-only review of local source and tests; no N1/USB access, cloud build or
firmware changes. Existing build/repack workflows remain unchanged.

Kernel
Exact Linux6.6.144 inputs are hash-checked. Only hci_bcm.c and meson_uart.c are
patched. Baud hardware-call count and error continuation remain unchanged;
the IRQ result has its own variable and does not replace the old err value.
UART logs run outside the spinlock, skip serial consoles and do not add per-byte
logging. The added REG5 read is configuration-only, not a destructive RX FIFO
read. TX/RX paths and hardware writes are unchanged. HCD, DT/GPIO, flow control
and eMMC isolation are untouched.
Software baud/counters are not electrical measurements. The original driver's
parity error path increments frame, so parity=0 does not exclude parity errors.

Collector
Requires isolation pass, tmpfs, adequate free space and GNU coreutils-timeout.
Current USB image lacks this dependency: the script cannot be used there as-is.
No automatic scan, power, pairing, service changes, mounting, writes to hardware
or uploads. Output is private tmpfs with bounded capture time and file size.
Fixed HCD hash is checked. Raw before/after kernel logs are retained; unreadable
kernel log or missing setup/baud-result markers fail closed with evidence kept.
The marker check accepts failure results: a baud failure is evidence, not a
reason to hide the record. UART sampler failures, final snapshot failures,
early exit, missing event data and unsupported timeout are incomplete.

Collector tests use temporary fake Linux files and command stubs, never a real
device. Coverage includes isolation, tmpfs/space, permissions, capture errors,
missing UART/event/marker data, HCD mismatch, dmesg failure and mock-process
TERM cleanup. Earlier 8-second test deadlines were too short for this Mac
fixture environment; the final suite passed with adequate test deadlines.

Limits and deployment gates
complete=yes means basic bounded capture checks passed: exit/time, snoop header
and nonempty event data, required kernel markers, snapshots and sampler. It is
not full btsnoop record parsing, complete initialization HCI capture, all
optional debugfs/logread data availability or proof of working Bluetooth.
No full ARM target compilation, BusyBox-ash/GNU-timeout/real-btmon integration,
physical UART measurement or hardware test has been performed. This review
therefore approves only the local preparation package. A future coherent
kernel/module/image build must verify dependency packaging, startup diagnostic
records and eMMC isolation, followed by final-image and bounded-test review.
Raw logs may contain nearby device information; they stay private. The explicit
source-file allowlist excludes runtime captures and unrelated private files.
